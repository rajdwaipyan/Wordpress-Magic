# Shared JavaScript Assets

This folder contains shared JavaScript utilities that can be used across multiple components.

## Purpose

- Common helper functions
- Reusable utilities
- Shared animations
- Event handlers

## Usage

Include shared JS files in your component when needed:
```html
<script src="../../assets/js/utilities.js"></script>
```

Or import in your component's JavaScript:
```javascript
import { helperFunction } from '../../assets/js/utilities.js';
```
