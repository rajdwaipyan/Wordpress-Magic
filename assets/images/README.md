# Shared Images

This folder contains shared image assets that can be used across multiple components.

## Purpose

- Placeholder images
- Icons and graphics
- Common UI elements
- Demo images

## Usage

Reference shared images in your components:
```html
<img src="../../assets/images/placeholder.jpg" alt="Description">
```

In CSS:
```css
background-image: url('../../assets/images/pattern.png');
```

## Guidelines

- Use optimized images (WebP format when possible)
- Include alt text descriptions
- Keep file sizes small for web performance
- Use descriptive filenames

## Contributing

When adding shared images:
- Optimize before uploading
- Use appropriate formats (JPEG for photos, PNG for graphics with transparency, SVG for icons)
- Include attribution if required
