# Shared CSS Assets

This folder contains shared CSS files that can be used across multiple components.

## Purpose

- Reusable utility classes
- Common animations
- Reset/normalize styles
- Typography styles
- Color schemes

## Usage

Include shared CSS files in your component when needed:
```html
<link rel="stylesheet" href="../../assets/css/utilities.css">
```

Or import in your component's CSS:
```css
@import url('../../assets/css/utilities.css');
```
