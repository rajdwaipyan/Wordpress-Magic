# Card Components

Beautiful, reusable card components for WordPress. Each card is designed to be self-contained and easy to integrate.

## Available Cards

- **[Image Card with Overlay](./image-card-overlay/)** - A beautiful image card with gradient overlay and hover effects

## Coming Soon

More card components will be added here. Contributions welcome!

## Usage

Each card component folder contains:
- `index.html` - Complete HTML structure
- `style.css` - Component styles
- `README.md` - Usage instructions and customization guide
