# WordPress Magic Components

A collection of individual, reusable design components for WordPress development.

## 📦 Categories

### [Cards](./cards/)
Beautiful card components with images, overlays, and animations.

### [Buttons](./buttons/)
Custom button designs with hover effects and various styles.

### [Forms](./forms/)
Form elements with modern styling and validation.

### [Navigation](./navigation/)
Menus, breadcrumbs, and navigation components.

### [Sliders](./sliders/)
Image sliders, carousels, and content sliders.

## 🚀 Quick Start

1. Browse the category folders above
2. Find a component you like
3. Open the component folder
4. Follow the README instructions to integrate it into your WordPress site

## 💡 Using Components

Each component is self-contained and includes:
- `index.html` - HTML structure
- `style.css` - Component styles
- `script.js` - JavaScript (if needed)
- `README.md` - Usage and customization guide

## 🎨 Component Structure

```
component-name/
├── index.html      # HTML structure with demo
├── style.css       # All component styles
├── script.js       # Interactive functionality (optional)
└── README.md       # Documentation and usage guide
```

## 🔧 WordPress Integration

All components can be integrated into WordPress using:
1. **Custom HTML Block** - Paste HTML directly in the editor
2. **Theme Template** - Add to theme files
3. **Shortcode** - Create a shortcode wrapper

See individual component READMEs for detailed integration instructions.
