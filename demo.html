How to Use

Hover over the cards below to see the Carbon Frame effects in action!

To use in WordPress: Add the class carbon-frame to any Elementor widget.

Experience the power of 3D transforms with smooth animations and glowing effects.

Feature Two

Feature Four

Feature Five

Text and icons transform in 3D space with synchronized depth effects.

Feature Six

Fully customizable with CSS variables for colors and animation speeds.

CSS Variables

Customize the appearance by modifying these CSS variables:

  • --magma-primary: #ff6b00 - Primary magma color (orange)
  • --magma-hot: #ffca00 - Hot accent color (yellow)
  • --frame-bg: #0a0a0a - Frame background (dark)
